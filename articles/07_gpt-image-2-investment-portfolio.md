GPT Image 2が出た翌日、Nano Banana 2時代から磨き込んできたプロンプトで画像を生成してみました。

文字描画精度99%、レイアウトもプロのデザイナーが組んだようなレベル。期待して既存プロンプトをそのまま流し込んだら、かえって品質が下がりました。なぜでしょうか。BizDev公開日誌 #7は、渡橋がお届けします。

## GPT Image 2が配った「80点」は、もう誰にも刺さらない

GPT Image 2の登場で、画像生成AIの性能は一段階上がりました。


| 観点       | 改善内容                                 |
| -------- | ------------------------------------ |
| 文字描画精度   | 標準的な評価で**約99%**に到達。日本語の描画も大幅改善       |
| 配置・レイアウト | キャッチコピー、CTAボタン、装飾の配置がプロのデザイナーレベル     |
| 思考能力     | 生成プロセスに**Thinking capabilities**を導入  |
| 商用利用     | 前世代が"アイデア出し"レベル → **そのまま広告に使える**レベルへ |


誰でもプロンプト一発でそれらしい広告バナーを作れるようになり、Xでも大量のAI生成バナーが出回っています。

> フルAIでバナーここまでできちゃうのか... GPT-Image-2、世界変わるな
> ――[@genel_ai](https://x.com/genel_ai/status/2045353488704774396)

> ChatGPTでもGPT image2が順次使えるようになっているようですが…結果、50回ほど試して当たりは3回…😭 今回は広告画像を作成してみました。
> ――[@midori_tatsuta](https://x.com/midori_tatsuta/status/2045253072289767815)

> ※投稿本文は公開時に確認・調整してください

驚きと興奮の声。しかしXに出回っているバナーやLPのサンプルを並べてみると、驚くほど似ています。文字組みのトンマナ、レイアウトの三分割、カラーパレット、装飾要素。社内検証でも「いっぱい出してるとどれも似たり寄ったりで、同じパターンを擦っている」と声が上がりました。

この現象は構造的に必然です。AIは学習データの"中央値"に最適化されます。みんなが同じモデルを叩けば、出力は平均に収斂します。デザイン性そのものが**コモディティ化**し、世間には「**平均的に綺麗だが、ユーザーニーズを掴めていないデザイン**」が蔓延します。AIが全員に80点を配った瞬間、**80点には何の価値もなくなる**のです。

## モデルが変わって見えた「二つの資産」

冒頭の話に戻ります。なぜ品質が下がったのでしょうか。

私たちはバナー広告の制作パイプラインを運用しています。戦略から逆算してデザインの方向性を複数案構想し、画像を生成し、多角的な観点で検品しています。この中で、Nano Banana 2に合わせてプロンプトを磨き込んできました。構図、装飾、要素の配置関係を一定の粒度で指定しており、プロンプトは自然と長文になっていました。

ところがGPT Image 2は「よしなに作る力」が大幅に上がっていました。デザイナーとして仕上がりすぎていると感じました。メンバーの一言が的確でした——「**制約を与えすぎるとへそを曲げる**」。具体的な要素配置を細かく指定すると、AIが無理やり守ろうとして全体のバランスが崩れてしまいます。パーセンテージ等の細かい数値指示はモデルが守れず、描写する必要のない文字やロゴを画面に描き込んでしまうこともありました。

対応は逆でした。**プロンプトの長さ・ディレクションの粒度を下げる方向に再調整**しました。色・質感・構図・雰囲気といったデザインの方向性だけを伝え、具体的な表現はAIに委ねるようにしました。そうしたら、むしろ質が上がりました。

この再調整が素早くできたのには理由があります。もともと多様な観点でプロンプトを構成していたため、その中から優先順位を付けることができました。GPT Image 2が自力で高精度に処理できるようになった観点はプロンプトから間引き、重要度の高い観点だけを残しました。過去の制作ログも蓄積されていたので、モデルの進化で解消された観点を特定して除外するだけで済みました。**詳細なプロンプティングの蓄積そのものが、高速なチューニングを可能にする資産だった**のです。

そしてもう一つ、検証観点はモデルが変わっても何一つ書き直す必要がありませんでした。例えば、AIの出力が多様性を維持しているか、ブランド規定から逸脱していないか、不要な要素が混入していないか——こうした評価軸はそのまま使えました。プロンプトを組み替えて、同じ評価軸で検証を回し直す。それだけで新モデルへの移行が完了しました。

<!-- img_02_two_assets.png: プロンプト蓄積×評価軸の二層構造 -->

積み上げてきたものの中に、**二つの資産**が見えました。多様な観点で構造化されたプロンプトの蓄積——モデルが変わっても素早く再調整できる基盤。そして評価軸——モデルが変わっても書き直す必要すらない、より耐久性の高い資産。これは理屈ではなく、実際にモデル移行を乗り越えて得た実感です。

## 「作れる」と「成果が出る」の間にある溝

しかし、評価軸を持っているだけでは足りません。

馬場が[#1](https://note.com/novasell_baba/n/nac2d03db35de)で書いた通り、「**『作れる』と『成果が出る』の間に、想像以上に深い溝がある**」。GPT Image 2はこの溝を埋めてはいません。溝の手前——「作れる」側を圧倒的に楽にしただけです。

そもそも、画像生成AIの進化は主に**デザイン能力の向上**です。しかしマーケティングで成果に効く要素は多層であり、デザイン能力はその一つに過ぎません。


| マーケで成果に効く要素             | AIの現状                          |
| ----------------------- | ------------------------------ |
| 誰に何を伝えるかの戦略設計（Who/Whatの見立て） | ⚠ 叩き台は出せるが、成果水準の判断は人が担う |
| ストーリー・フックの構造設計          | ⚠ パターン提案は可能。刺さるかの判断は人次第     |
| 勝ちパターンの横展開ロジック          | ⚠ 類似案の列挙は得意。文脈に合う選別は人が要る     |
| 顧客固有の事業文脈               | ❌ 一次情報を持たないAIには原理的に難しい        |
| **クリエイティブ表現（デザイン/コピー）** | **✅ GPT Image 2等でほぼ実用レベルに**   |


GPT Image 2が大きく進化させたのは最後の一行——クリエイティブ表現の領域です。それ以外の要素も「AIは何もできない」わけではありません。叩き台を出したり、パターンを列挙したりする力は十分にあります。しかし、**それを「この顧客に、この文脈で、この訴求が刺さる」という成果水準に引き上げるのは、依然として人間の判断です**。

**「デザインの民主化」は進んでいますが、「成果の民主化」を意味するわけではありません**。馬場が[#3](https://note.com/novasell_baba/n/n323d68c57427)で「ツール性能は半年で陳腐化する。重要なのは事業として勝ち続ける構造」と書いたのは、まさにこの構図です。

そして、この溝を越えるための設計——業務プロセスのどこにAIを組み込み、どこに人間の判断を残すか——こそが、私たちの仕事の中核にあります。市岡が#2で指摘した通り、AIが「平均点」を超えるには、現場の暗黙知を言語化して仕組みに落とす作業が不可欠です。

## どこに張り、どこから手を引くか

この認識のもとで、私たちは業務を**「AIの進化速度」と「成果への寄与度」の2軸**で仕分け、投資配分を決めています。


| 軸           | 内容                                             |
| ----------- | ---------------------------------------------- |
| **AIの進化速度** | 汎用モデルの自然進化で代替が進むスピード。速いほど、自社投資した資産の陳腐化リスクが高い   |
| **成果への寄与度** | 広告成果（CVR / CPA / 売上）に直接効くか。寄与が大きいほど、投資リターンが大きい |


この2軸で4象限を切り、業務ごとにアクションを仕分けます。

<!-- img_03_portfolio.png: 2軸4象限の投資マトリクス -->

```
                    成果寄与 大 →

進化速度        ┌──────────────┬──────────────┐
 速い           │ A 追従＋検証  │ C 捨てる     │
                │ サイクル化    │              │
                ├──────────────┼──────────────┤
                │              │              │
 遅い           │ B 集中投資    │ D 最低限維持 │
                │ (本丸)       │              │
                └──────────────┴──────────────┘
```

**AIの進化が速い領域**（画像生成、コピー生成、レポート要約など）では、プロンプトを消耗品と割り切り、追従コストを最小化しています。評価軸を構造化して、モデルが変わっても同じ問いで検証できる体制を整えています。冒頭の「品質が下がった → 粒度を調整し、評価軸で乗り切った」は、まさにこの原則の実践です。

**AIが代替しにくく、成果に直結する領域**（戦略設計、N1構造化、ストーリー設計、勝ち筋抽出、顧客接点）。**ここに本丸を置いています**。汎用モデルの学習データからは獲得できない領域であり、顧客の事業文脈に入り込んで自ら蓄積する以外に方法はありません。私たちのリソースの大半はここに集中しています。

## AIの内側と外側——両輪で初めて成果が出る

そしてもう一つ、大事な観点があります。

AIの内側（モデルやプロンプトやエージェント設計）をいくら磨いても、**AIの外側——渡すインプットの質が貧弱なら、"それらしい"出力にしかなりません**。

例えばN1分析。トッププレイヤーの思考プロセスを構造化してプロンプトに落とすのは「内側」の投資として大前提です。しかしそれだけでは、AIは学習データから"ありがちな"ペルソナを推測するだけになってしまいます。**実在する顧客のリアルな声、現場で拾った一次情報**——この「外側」のインプットがなければ、AIの出力は現実とのギャップを抱え続けます。これはN1に限らず、勝ち筋抽出でもクリエイティブ評価でも同じ構造です。

私たちはこの「AIの外側」にも同じ重みで投資しています。

- **リアルな声の収集機構**: N1インタビュー、CS・SNSの生コメント、顧客社内のデータ。AIでは代替できない、物理世界での顧客接点そのもの
- **ドメインデータの蓄積**: 過去案件の実績・勝ちパターンを横断参照できる仕組みを整える
- **市場・競合の広告データ収集**: 世間に出ている広告クリエイティブを収集・分析し、市場動向や競合の打ち手を把握する

泥臭く現場に入り、一次情報を取りに行きます。AIの内側と外側、両輪を設計して初めて、成果は再現可能になります。

## まとめ

- AIが80点を量産する時代、80点で満足する側にいれば勝負にならない
- 構造化されたプロンプトの蓄積と、モデル非依存の評価軸——この二つの資産が、モデル移行を高速に乗り越える基盤になる
- 投資は「溝の向こう側」に集中する。AIの進化が速い領域は追従コストを最小化し、成果に直結する設計知見に本丸を置く
- AIの内側と外側、両輪が揃って初めて成果は再現できる

---

モデルは変わる。80点は誰でも出せるようになる。デザインの民主化は、成果の民主化を意味しない。

**それでも残るのは、「この80点は成果に効くのか」と問える眼と、問い続ける仕組みだけだ。**

私たちが日々取り組んでいるのは、プロンプトの調整ではありません。業務プロセスのどこにAIを組み込み、どこに人間の判断を残すか。顧客ごとの事業文脈の中で、その設計を磨き続けること。AIツールの使い方を知っているだけでは届かない、事業の構造そのものを設計する仕事です。
